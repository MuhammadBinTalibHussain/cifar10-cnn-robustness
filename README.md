# CIFAR-10 Image Classification with CNNs

A deep learning project exploring CIFAR-10 image classification using PyTorch and Convolutional Neural Networks (CNNs), with a focus on data augmentation, regularization, training optimization, model robustness, and systematic ablation studies.

## Overview

This project investigates how different training strategies affect image classification performance when only a small amount of labeled training data is available.

The notebook develops a baseline CNN, experiments with data augmentation and regularization techniques, compares alternative training configurations, and analyzes model errors on clean and shifted image datasets.

## Objectives

- Build a baseline CNN for CIFAR-10 image classification.
- Train and validate models using a limited dataset.
- Explore data augmentation strategies to improve generalization.
- Apply regularization and learning-rate scheduling.
- Conduct ablation studies to compare training configurations.
- Evaluate performance on clean and distribution-shifted test images.
- Analyze classification errors using a confusion matrix and per-class accuracy.

## Dataset

The project uses the **CIFAR-10** image classification dataset, which contains 32 × 32 color images from 10 classes.

The classes are:

- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

### Limited-data setup

The notebook selects 50 images per class from the CIFAR-10 training batches:

- **Training set:** 400 images (40 per class)
- **Validation set:** 100 images (10 per class)

This setup allows experiments with image classification under limited-data conditions.

The project also evaluates models on the clean CIFAR-10 test set and a separate shifted test dataset.

## Methodology

### Part A: Baseline CNN

A baseline CNN with an Inception-style block is trained using PyTorch. The model establishes a reference point for evaluating subsequent training improvements.

The baseline uses cross-entropy loss and the Adam optimizer.

### Part B: Data Augmentation

Several image transformations are applied during training to increase data diversity:

- Random cropping
- Random horizontal flipping
- Random rotation
- Color jittering

The goal is to improve generalization when training examples are limited.

### Part C: Regularization and Training Design

The project explores additional techniques to reduce overfitting and improve training:

- Dropout
- Weight decay
- Label smoothing
- Learning-rate scheduling
- Early stopping and best-model selection
- Random grayscale conversion
- Random erasing

### Part D: Ablation Study

Multiple training configurations are compared across three random seeds: 42, 43, and 44.

The configurations include:

1. No augmentation
2. Geometric augmentation only
3. Photometric augmentation only
4. Combined geometric and photometric augmentation
5. Combined augmentation with random erasing
6. Combined augmentation with Mixup and label smoothing

Validation, clean-test, and shifted-test performance are compared to investigate the contribution of individual training strategies.

### Part E: Error Analysis

The selected model is evaluated through:

- Confusion matrix analysis
- Per-class classification accuracy
- Overall clean-test accuracy
- Evaluation under hidden image corruption
- Analysis of performance changes under corrupted inputs

These analyses help identify classes and image conditions where the model has difficulty making correct predictions.

## How to Run

1. Clone or download this repository.
2. Obtain the CIFAR-10 data files and the required shifted test dataset.
3. Place the required dataset files in the notebook's working directory.
4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `DL_ASS02_23F_0577.ipynb`.
6. Run the notebook cells sequentially, beginning with dataset preparation.

**Note:** The notebook expects local dataset files, including `data_batch_1` through `data_batch_5`, `test_batch`, and `shifted_test.npz`. Ensure these files are available before running the experiments.
